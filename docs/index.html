macOS 13+。Apple Silicon 和 Intel 各打一份。未签名，别人电脑上打开时，到系统设置 → 隐私与安全性，点「仍要打开」。

macOS 13+. Separate builds for Apple Silicon and Intel. The app is unsigned — on another Mac, open System Settings → Privacy & Security and click Open Anyway.

VibeShare 适合同一局域网内的即时预览和临时分享，不替代正式部署。等网页准备好上线时，再交给服务器或静态托管平台。

VibeShare is built for instant previews and temporary sharing on the same local network. It does not replace production hosting — deploy when your page is ready to ship.
